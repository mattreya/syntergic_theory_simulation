# Syntergic Theory Simulation

This repository contains a computational model of Dr. Jacobo Grinberg-Zylberbaum's **Syntergic Theory**, simulating the emergence of complex biological forms and consciousness from a fundamental holographic energy field.

## The Theory
The Syntergic Theory posits that human perception is the result of an interaction between:
1. **The Lattice (Pre-space Matrix):** A high-density, holographic quantum field containing all potential information.
2. **The Neuronal Field:** A macroscopic energetic operator generated by the brain.
3. **Perceptual Reality:** The interference pattern resulting from their interaction. High neural coherence yields a direct, undistorted reflection of the Lattice, while low coherence yields rigid, filtered "standard" reality.

## The Simulation Model

This project models these concepts in Python, demonstrating how abstract energetic wave functions self-organize into structures resembling biological cells. 

### Core Components
* **`lattice.py`**: Represents the underlying multidimensional pre-space matrix (phase and amplitude).
* **`multi_agent.py`**: The swarm engine simulating "Proto-Agents." It uses harmonic oscillation (`cos(2πfr) + i*sin(2πfr)`) to model the Neuronal Field.
* **`transformation.py`**: The Perceptual Sieve. Generates the interference pattern (Perceived Reality) using frequency-domain convolution.

### Physics Progression & Transferred Potential
The physics engine evolved to successfully model Grinberg's "Transferred Potential" experiments:
1. **Phase 1 (Static):** Single-agent interference patterns showing reality distortion.
2. **Phase 2 (Brownian Drift):** Multi-agent random drift with resonance chaining and area-conservation ($R_{new} = \sqrt{r_1^2 + r_2^2}$).
3. **Phase 3 (Empathetic Gravity):** Agents no longer drift randomly. They scan the Lattice and calculate a directional attraction vector toward the largest neighbor vibrating at their exact frequency ($\omega$). 

By introducing this "desire to connect," the simulation organically generates **cymatic standing waves**, and the Perceived Reality interference patterns spontaneously take on the morphology of **neural cells**.

## Getting Started

### Prerequisites
- Python 3.8+
- Jupyter Notebook

### Installation
1. Clone the repository
2. Create a virtual environment and install dependencies:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r syntergic-model/requirements.txt
```

### Running the Simulation
Launch the Jupyter Notebook to run the interactive Swarm Simulation:
```bash
jupyter notebook syntergic-model/notebooks/simulation.ipynb
```

## Glossary

- **Cellular Automaton (CA)**: A discrete computational model consisting of a grid of cells that evolve step-by-step. At each step, a cell changes its state (e.g., "alive" or "dead", 1 or 0) based on simple rules concerning the states of its immediate neighbors. 
- **Computational Irreducibility**: A concept by Stephen Wolfram stating that for many complex systems (like certain Cellular Automata), you cannot predict their future state using a shortcut or formula; the only way to know the outcome is to actually run the simulation.
- **Class 4 Behavior (Mechanoidal Phase)**: A rare classification of cellular automata where complex, stable structures emerge that move, interact, and survive over time without being purely repetitive or purely chaotic.
- **Lattice (Pre-space Matrix)**: The fundamental, underlying informational field from which physical reality is constructed. Modeled here as an evolving Cellular Automaton.
- **Neuronal Field**: The macroscopic energy wave generated by the brain (or "agent"), which acts as an observer/filter.
- **Perceptual Reality**: The interference pattern that forms when the Neuronal Field interacts with the Lattice, resulting in what we perceive as reality.
